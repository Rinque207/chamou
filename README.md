# Chamou

O **Chamou** é um projeto acadêmico desenvolvido por estudantes de Ciência da Computação.

A proposta é criar uma plataforma que conecte pessoas que precisam de serviços a profissionais disponíveis, reunindo diferentes tipos de prestadores em um único ambiente.

## 💡 Sobre o projeto

Encontrar profissionais como eletricistas, jardineiros, piscineiros, encanadores e outros prestadores de serviço nem sempre é simples.

O Chamou busca centralizar essa busca em uma plataforma, facilitando o contato entre clientes e profissionais.

## 🎯 Objetivo

O projeto pretende permitir:

- cadastro de usuários;
- cadastro de prestadores de serviços;
- busca de profissionais por categoria;
- visualização de informações dos prestadores;
- solicitação de serviços.

## 🛠️ Tecnologias

As tecnologias utilizadas serão adicionadas conforme o desenvolvimento do projeto avançar.
